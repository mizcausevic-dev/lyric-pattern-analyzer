Lyric Pattern Analyzer

Deterministic counts. No quality score. No lyric corpus in this file.

1. Product

A local app that measures structure and repetition in lyric drafts the user already wrote.

2. Who

Songwriters comparing their own drafts. Not a publisher, not a co-writer, not a critic.

3. Why it wins

Every figure carries n. MATTR instead of naive TTR. Lyrics never leave the machine in the desktop build.

4. Structure

Pure TypeScript core → SQLite in Electron main → sandboxed React renderer. Preview uses memory + nonce words.

5. Discovery

Private GitHub. Pages preview is a public demo of the UI on synthetic text, noindex.

6. Engage

Paste a draft, record language, analyze, compare two versions, inspect n-grams and section Jaccard.

7. Convert

No account. Conversion is “keep using it on a song.” Export statistics, not the catalog.

8. Money

Not a billed product in this build. Reuses as a local text-pattern workstation for poems, sermons, or scripts without changing the no-score rule.

9. Launch

Private repo + Pages preview. Desktop unsigned. No auto-update.

10. Improve

Optional user-supplied pronunciation dictionary only after license verification. Keep rhyme unlabeled approximate.

Pipeline

KPI (local only, no GA4): drafts analyzed, comparisons exported, snippet-opt-in rate. Events stay off-network in this product.
